# Iian Kehn

Personal website at https://www.iiankehn.com/. Plain HTML and CSS, with no framework, package installation, or build step.

## Pages

- Home: personal introduction.
- Projects: Acute Web, unified Slate, CORE, and CORE Dev.
- About: biography, Amazon role, personal interests, and social icon buttons.

## Design

A modern interpretation of Metro: expressive typography, flat square project tiles, open layouts, and a text-based navigation with an accent underline. Black surfaces and warm amber accents are used throughout. Small circular portraits and social icon buttons are retained.

The site is dark-only, regardless of the device preference. There are no appearance controls or stored theme settings. Responsive layouts, visible keyboard focus, and reduced motion support are included.

## Preview and publish

Run `python3 -m http.server 8000` from the repository. GitHub Pages publishes the root of `main`. Preserve `CNAME`.
